# Synthetic data

The files in this folder are generated deterministically by `scripts/01_generate_synthetic_data.R` using seed 2026. They are entirely synthetic: **no real patient, participant, institutional, or unpublished research data** are used.

`synthetic_preventive_health.csv` contains 800 simulated participants and 21 variables. `data_dictionary.csv` defines the variables and units. Run `source("run_all.R")` to regenerate both files.
