# Preventive Medicine Analysis Demo

Reproducible analysis of synthetic clinical, behavioral, and metabolic health data in R.

This project demonstrates how lifestyle exposures, metabolic biomarkers, and clinically interpretable outcomes can be integrated in a preventive-medicine analysis workflow.

## Joint Exposure Analysis

The planned analysis will examine combinations of sedentary behavior and interruption patterns to illustrate how multiple modifiable lifestyle exposures can be evaluated jointly in preventive-health research.
